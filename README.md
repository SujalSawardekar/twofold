# Twofold — Landing Page

Modern, high-performance web experience for **Twofold**, an Indian manufacturer and exporter of notebooks and paper stationery.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **UI & Animation**: GSAP, Lenis Smooth Scroll, Vanilla CSS Modules
- **Interactive Audio**: Web Audio API Procedural Sound Engine
- **Visualizations**: D3-geo with TopoJSON world atlas

## Features
- Interactive 3D Notebook Shelf with live specification inspection
- Dynamic World Export Map with interactive trade routes
- Headroom floating navigation bar with mobile drawer
- Web Audio sound effects with floating mute/unmute toggle
- Responsive, typography-focused editorial layout

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm run start
```
